# Weather App

A simple, responsive weather application that lets users check real-time weather conditions for any city around the world. Built as a foundational project to practice API integration and DOM manipulation.

## Features

- 🔍 Search weather by city name
- 🌡️ Displays temperature, humidity, and wind speed
- ☁️ Shows current weather conditions (sunny, rainy, cloudy, etc.) with icons
- 📱 Responsive design for mobile and desktop
- ⚡ Real-time data fetched from a weather API

## Tech Stack

- **HTML, CSS, JavaScript**
- **Weather API** (e.g., OpenWeatherMap) for live weather data
- **Fetch API** for handling async requests
